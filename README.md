# Task 34: Regression Predictions

## Veda Technology – AI & ML Internship

### Objective
To use a trained Linear Regression model to predict salaries based on years of experience and compare actual values with predicted values.

### Dataset
**Salary vs Experience Dataset**

The dataset contains:
- YearsExperience
- Salary

### Tools and Libraries
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

### Implementation
1. Imported the required Python libraries.
2. Loaded the salary and experience dataset.
3. Separated input and output features.
4. Split the dataset into training and testing sets.
5. Trained a Linear Regression model.
6. Generated predictions using `model.predict()`.
7. Compared actual and predicted salary values.
8. Evaluated the model using MAE and R² score.
9. Predicted salaries for new experience values.

### Expected Outcome
- Successfully trained a Linear Regression model.
- Generated salary predictions for test data.
- Compared actual and predicted values.
- Generated predictions for new input values.

### Conclusion
This task demonstrates how a trained Linear Regression model can make predictions using new input values. It also helps understand model evaluation and the comparison between actual and predicted results.
